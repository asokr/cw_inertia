# История остатков Ozon

## Права доступа

- Permission: `subscriber oz stock history`
- Middleware панели: `auth`, `verified`, `panel.access`, `wb.cabinets.migrated`, `permission:subscriber oz stock history`
- Кабинет: единый Ozon (`oz_cabinets` / `selected_oz_cabinet_id`) — см. [oz-cabinets.md](oz-cabinets.md)

## Назначение

Инструмент показывает, сколько товара лежало на складах Ozon (FBO) в разные дни: товар → кластер → склад.

Ozon не отдаёт историю остатков за прошлые даты. Система сама снимает срез за **завершённый московский день** (вчера). Сегодняшние остатки не пишутся: если сегодня 5-е, последние данные — за 4-е.

Отслеживание **включает пользователь**. Пока оно выключено, новые дни не добавляются. Уже сохранённая история остаётся и живёт по выбранному сроку хранения.

## Сценарий

1. Открыть `/panel/oz/stock-history`, при необходимости выбрать кабинет в шапке.
2. Указать, сколько дней хранить историю (по умолчанию 90, максимум 180).
3. Нажать «Начать отслеживание».
4. Сначала загружаются **все товары кабинета**. Без каталога отслеживание не включается.
5. Затем сохраняются остатки за вчера.
6. Каждый день в 00:05 МСК дописывается снимок за вчера, пока отслеживание включено.
7. «Остановить отслеживание» — новые дни не пишутся, история на экране остаётся.

## Ozon Seller API

База `https://api-seller.ozon.ru/`, ключи кабинета.

| Метод | Зачем |
|-------|--------|
| `POST /v3/product/list` | Список товаров при старте и каждом снимке |
| `POST /v3/product/info/list` | Артикул, название, фото, FBO SKU |
| `POST /v1/cluster/list` | Кластеры России и склады FBO |
| `POST /v1/analytics/stocks` | Остаток «доступно к продаже» по SKU × склад × кластер (пачки до 100 SKU) |

Аналитика Ozon обновляется около 07:00 и 16:00 UTC (10:00 и 19:00 МСК). Снимок ставится в 00:05 МСК и датируется вчерашним днём: на 5-е число пишутся остатки за 4-е.

FBS/rFBS в инструмент не входят.

## Схема БД

- `oz_stock_history_settings` — срок хранения, флаг и статус отслеживания
- `oz_stock_history_snapshots` — статус дневного сбора (`pending` / `running` / `done` / `failed`)
- `oz_stock_history_products` — справочник карточек (`is_active` для исчезнувших из кабинета)
- `oz_stock_history_warehouses` — склад и кластер
- `oz_stock_history_items` — факт остатка на дату

Правило записи:

- пары товар–склад с остатком > 0 пишутся всегда;
- ноль пишется только если эта пара уже встречалась (товар закончился — склад остаётся в истории);
- позиции, у которых за выбранный период остаток всегда 0, в списке не показываются;
- склады, где товара никогда не было, не показываются.

## Настройки хранения

- По умолчанию 90 дней, минимум 7, максимум 180 (полгода).
- Старые дни удаляются автоматически (`subscriber:oz-stock-history-prune` в 01:30 МСК и сразу при уменьшении срока).

## Web-маршруты

Prefix: `/panel/oz/stock-history` · name: `subscriber.oz.stock-history.*`

| Method | URL | Назначение |
|--------|-----|------------|
| GET | `/` | Workspace |
| GET | `/status` | JSON статуса отслеживания |
| GET | `/products` | JSON списка товаров |
| GET | `/products/{sku}` | JSON кластеров и складов товара |
| PUT | `/settings` | Срок хранения |
| POST | `/start` | Загрузить товары и включить отслеживание |
| POST | `/stop` | Остановить |
| POST | `/sync` | Повторить снимок за вчера |

## Очередь

```
php artisan queue:work --queue=oz_stock_history,default --tries=2 --timeout=1800
```

| Job | Timeout | Unique |
|-----|---------|--------|
| `ProcessOzStockHistoryStartJob` | 1800 | кабинет |
| `ProcessOzStockHistorySnapshotJob` | 1800 | кабинет + дата |

Расписание: `subscriber:oz-stock-history-snapshot` в 00:05 МСК (только `tracking_enabled`), prune в 01:30 МСК.

## UI

Страница: `resources/js/Pages/Subscriber/Oz/StockHistory/Index.vue`.

Таблица по дням: колонки дат (новые слева), в ячейках остаток в штуках. На строке товара, направления и склада история видна сразу — дни не переключаются. Раскрытие товара показывает направления, раскрытие направления — склады. Поиск по артикулу и названию. Кнопка «На весь экран» открывает таблицу на весь экран (как в ценообразовании). По 100 товаров на страницу. По умолчанию показываются все сохранённые дни в пределах срока хранения.

Тексты для пользователя — без технических названий API.
